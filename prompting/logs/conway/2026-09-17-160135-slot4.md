Sos un ingeniero de software especializado en Python y en algoritmos discretos. Tu tarea es implementar correctamente el Juego de la Vida de Conway a partir de la especificación completa que sigue.

CONTEXTO

Necesito un único archivo llamado vida.py para ejecutar desde la línea de comandos. El archivo será evaluado automáticamente por tests externos de la cátedra. No podés asumir paquetes de terceros ni modificar los tests.

CONTRATO OBLIGATORIO

El programa debe ejecutarse exactamente así:

    python3 vida.py <archivo_estado_inicial> <generaciones>

El archivo de estado inicial contiene una grilla rectangular:
- Una línea representa una fila.
- Cada carácter representa una célula.
- "#" significa célula viva.
- "." significa célula muerta.
- Todas las filas tienen el mismo ancho.
- La grilla puede tener cualquier tamaño rectangular válido.

El mundo es finito y tiene exactamente el tamaño de la grilla inicial:
- Las células fuera de los bordes se consideran siempre muertas.
- No existe wrap-around.
- El borde superior no es vecino del borde inferior.
- El borde izquierdo no es vecino del borde derecho.

El programa debe:
1. Leer el archivo indicado en el primer argumento.
2. Leer el número de generaciones indicado en el segundo argumento.
3. Simular exactamente esa cantidad de generaciones.
4. Imprimir por stdout únicamente la grilla final.
5. Mantener el mismo formato: una fila por línea, sin explicaciones, encabezados ni texto adicional.
6. Si generaciones es 0, imprimir exactamente el estado inicial sin modificarlo.
7. Usar únicamente la biblioteca estándar de Python.
8. Ser un único script autocontenido llamado vida.py.

REGLAS DEL JUEGO DE LA VIDA

Cada célula considera sus ocho posiciones vecinas: arriba, abajo, izquierda, derecha y las cuatro diagonales.

En cada generación, todas las células se actualizan simultáneamente según el estado de la generación anterior:

- Una célula viva sobrevive si tiene exactamente 2 o 3 vecinos vivos.
- Una célula viva muere si tiene menos de 2 vecinos vivos o más de 3 vecinos vivos.
- Una célula muerta nace si tiene exactamente 3 vecinos vivos.
- Una célula muerta permanece muerta en cualquier otro caso.

IMPORTANTE:
- Las actualizaciones deben ser simultáneas; no modifiques la grilla mientras todavía estás calculando la misma generación.
- No cuentes como vecinos las posiciones fuera de la grilla.
- No uses condiciones toroidales ni índices con wrap-around accidental.
- Conservá el alto y el ancho de la grilla durante toda la simulación.

import sys

def main():
    if len(sys.argv) != 3:
        sys.exit("Uso: python3 vida.py <archivo_estado_inicial> <generaciones>")

    archivo = sys.argv[1]
    try:
        generaciones = int(sys.argv[2])
        if generaciones < 0:
            raise ValueError
    except ValueError:
        sys.exit("El número de generaciones debe ser un entero no negativo.")

    try:
        with open(archivo, 'r', encoding='utf-8') as f:
            lineas = f.read().splitlines()
    except FileNotFoundError:
        sys.exit(f"No se encontró el archivo: {archivo}")

    if not lineas:
        sys.exit("El archivo de estado está vacío.")

    # Validar que todas las filas tengan el mismo ancho
    ancho = len(lineas[0])
    for fila in lineas:
        if len(fila) != ancho:
            sys.exit("Las filas no tienen el mismo ancho.")

    alto = len(lineas)
    # Convertir a lista de listas de caracteres para mutar
    grid = [list(fila) for fila in lineas]

    def contar_vecinos(g, x, y):
        vecinos = 0
        for dx in (-1, 0, 1):
            for dy in (-1, 0, 1):
                if dx == 0 and dy == 0:
                    continue
                nx, ny = x + dx, y + dy
                if 0 <= nx < alto and 0 <= ny < ancho:
                    if g[nx][ny] == '#':
                        vecinos += 1
        return vecinos

    for _ in range(generaciones):
        nueva = [['.' for _ in range(ancho)] for _ in range(alto)]
        for i in range(alto):
            for j in range(ancho):
                vivos = contar_vecinos(grid, i, j)
                if grid[i][j] == '#':
                    if vivos == 2 or vivos == 3:
                        nueva[i][j] = '#'
                else:
                    if vivos == 3:
                        nueva[i][j] = '#'
        grid = nueva

    # Imprimir la grilla final
    for fila in grid:
        print(''.join(fila))

if __name__ == "__main__":
    main()
